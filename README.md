# Проєкт Команди 12: Знаходження донора для реципієнта за HLA-алелями

**Звіт для проміжного іспиту**

Після першої зустрічі з ментором команда розпочала активну фазу розробки:
-  Детально ознайомилися з роботою систем контролю версій **Git** та **GitHub**.
-  Створено та налаштовано репозиторій для спільної роботи.
-  Проведено декомпозицію задачі та розподілено ролі між учасниками.

Кожному учаснику команди присвоєно окрему частину роботи для реалізації алгоритму та інтерфейсу:

| Учасник | Відповідальність / Завдання |
| :--- | :--- |
| **Віталій** |  **Інтерфейс програми:** Розробка UI для взаємодії з користувачем. |
| **Софія** |  **Обробка даних:** Робота з інформацією про донорів та реципієнтів (парсинг, збереження). |
| **Северин** |  **Оцінка збігів:** Логіка порівняння та оцінки сумісності HLA-алелів. |
| **Назар** |  **Матриця витрат:** Створення матриці витрат для роботи Угорського алгоритму. |
| **Ігор** |  **Алгоритм:** Реалізація Угорського алгоритму для знаходження оптимальних пар. |
